## What They Do

Tern builds software for **Air Navigation Service Providers (ANSPs)** — the organisations that run [[ATC Units]] around the world.

Core offering: help ATCOs manage aircraft safely and efficiently using software tools layered on top of surveillance data and flight plans.

## How Tern Fits in the Industry

```
Pilots → Aircraft → Surveillance (radar/ADS-B)
                          ↓
                   [Tern Software] ← flight plans
                          ↓
                      ATCOs → separation, safety
```

Tern sits in the middle: ingesting raw surveillance + flight data, processing it, and presenting it to controllers.
