

### Merge Request

## What[](https://app.clickup.com/t/9012329445/what "Issue in ClickUp")

Split the monolithic `TrackLabelEditorController` into three specialized controllers (`TrackLabelRuntimeDataController`, `TrackLabelDataController`, and `TrackLabelIOController`) to separate runtime preview state, layout data management, and file I/O operations.

## How[](https://app.clickup.com/t/9012329445/how "Issue in ClickUp")

- **`TrackLabelRuntimeDataController`**: Isolated preview conditions. such as active visibility state, active control type, and holding state, into a standalone class that emits a single `changed()` signal when settings update.
- **`TrackLabelDataController`**: Extracted active label variant management, layout row tracking, field selection, and field addition logic. Reads state from `TrackLabelRuntimeDataController` to trigger field visibility re-evaluations.
- **`TrackLabelIOController`**: Centralized all XML configuration tree operations (loading, saving, default initialization) and background loading status (`isLoading`), passing loaded trees directly to the data controller.
- **Wiring & Instantiation**: Updated `TrackLabelEditorInstantiator` to sequentially instantiate and inject these dependencies. Connected `m_runtimeDataController::changed` to `m_dataController::reevaluateActiveLayoutVisibility`, and updated `TrackLabelFileBrowserController` to target `TrackLabelIOController` directly.
