

- [ ] Ensure each Qobject instance (FieldInterface, etc) has a parent
	- *What this does*
	  **The QObject has a Parent**
	  Each QObject that has a parent, will clean itself up whenever its parent is deleted. 
	  Also If QObject doesn't have a parent, and is passed as a property into QML, then QML will take responsability of cleaning the pointer up, without deleting contents of pointer.
	  Meaning, if Qobject has parent -> QML knows that C++ is responsible of the pointers lifecycle.
	  **The QObject has NO Parent**
	  Who deletes it? The QML Garbage Collector. * The Danger: QML will automatically delete your C++ object from memory as soon as JavaScript determines it's no longer being used in QML. If your C++ model still holds a raw pointer to it in m_cells, your C++ list now points to garbage memory, causing an immediate crash the next time C++ accesses it.
- [ ] Use `setParent` to safely move pointers of `FieldInterface` between instances of `RowCellModel` within `RowListModel`.
      1. The Sending Container (Container A)
        You remove the pointer from your local list and emit it. Do not call deleteLater().

```C++
void ContainerA::moveCell(int position) 
{
    beginRemoveRows(QModelIndex(), position, position);
    
    // Take the pointer out of the list (stops Container A from tracking it)
    QObject* cell = m_cells.takeAt(position); 
    
    endRemoveRows();

    if (cell) {
        // Emit the signal to pass the raw pointer across the bridge
        emit cellMoved(cell); 
    }
}
```

2. The Receiving Container (Container B)
This is where you accept the pointer, claim ownership by changing its parent, and store it.

```C++
// This slot is connected to ContainerA::cellMoved
void ContainerB::onCellReceived(QObject* cell) 
{
    if (!cell) return;

    int insertPosition = m_cells.size();
    beginInsertRows(QModelIndex(), insertPosition, insertPosition);

    // 1. Change the parent to Container B (or Container B's internal manager)
    cell->setParent(this); 

    // 2. Add the pointer to Container B's internal tracking list
    m_cells.append(cell); 

    endInsertRows();
}
```
