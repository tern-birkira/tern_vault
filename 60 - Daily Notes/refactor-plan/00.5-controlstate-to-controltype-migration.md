# Migrate ControlState → ControlType

## Goal

Replace all usage of `commontypes::flight::ControlState` with `commontypes::tracklabel::ControlType`
throughout the track-label-editor codebase. `ControlType` is the XSD-native enum that already
exists in `TrackLabelTypes.h`. `ControlState` (in `FlightTypes.h`) is a near-duplicate with
different sentinels (`Unknown`/`ControlStateCount` vs `NotSet`/`All`).

Using `ControlType` directly eliminates the `toControlType()` converter in `FieldInterface.cpp`
and removes the dependency on `FlightTypes.h` from the track-label-editor entirely.

## Files to Change

| File | Change |
|------|--------|
| `FieldInterface.h` | Remove `#include "FlightTypes.h"`. Change `evaluateVisibility` param: `ControlState` → `ControlType` |
| `FieldInterface.cpp` | Delete entire `toControlType()` anonymous-namespace function. Change `evaluateVisibility` signature. Use `globalControlType` directly in `controlStates.contains()` |
| `FieldListModel.h` | Remove `#include "FlightTypes.h"`. Change `evalVisibility` param: `ControlState` → `ControlType` |
| `FieldListModel.cpp` | Change `evalVisibility` signature |
| `TrackLabelEditorController.h` | Remove `#include "FlightTypes.h"`. Change `activeControlState` → `activeControlType` using `ControlType`. Change member type. |
| `TrackLabelEditorController.cpp` | Update setter + reevaluate to use `ControlType` |

**Note:** After the full refactor, `TrackLabelEditorController` is deleted anyway — so the
changes to it are only needed if we do this migration BEFORE the controller split.
If done DURING the split, simply write the new controllers with `ControlType` from the start.

## Recommended: Do during the split (not as a separate pre-step)

Since we're about to extract everything into new controllers anyway, it's cleaner to:
1. Write `TrackLabelRuntimeDataController` with `ControlType` from day one
2. Write `TrackLabelDataController::reevaluateActiveLayoutVisibility()` passing `ControlType`
3. Update `FieldInterface::evaluateVisibility()` and `FieldListModel::evalVisibility()` signatures
4. Delete the `toControlType()` converter
5. Remove `FlightTypes.h` includes from all touched files

This avoids a throw-away intermediate commit that changes the old controller.

## FlightTypes.h disposition

After migration, `FlightTypes.h` is only used for `CoordinationState` (which nothing in the
track-label-editor references). If no other consumer exists in the codebase:
- Can be removed from `asd.editor.commontypes/CMakeLists.txt`
- Or left in place (dead code, but harmless) — check if other editors use it

```bash
grep -r "FlightTypes\|CoordinationState\|commontypes::flight" source/apps/ --include="*.h" --include="*.cpp"
```

If only the track-label-editor uses it → delete.

## ControlType default value mapping

| Old (ControlState) | New (ControlType) |
|-------------------|-------------------|
| `Unknown` | `NotSet` |
| `ControlStateCount` | `All` |
| All 9 named states | Identical names, 1:1 |
