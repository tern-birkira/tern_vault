# Merge Request

## What

Refactors XML attribute serialization to be driven by a registry-based type-serializer lookup, and adds default-value suppression for several track-label attributes so they're only written when they differ from their XSD-defined defaults. Also fixes a couple of related model bugs (an extra empty field row leaking into serialized output).

## How

`XmlModelSerializer` walks a tree of `IXmlSerializable` `QObject`s and converts it to/from a `tern::xml` DOM tree.  
Serializing: for each object, it creates an `XmlElement` named after `xmlTagName()`, writes its `xmlAttributeMap()` properties as attributes (converting each value to an XSD string via the registry's type-serializer lookup), then recurses into `xmlChildren()` to build nested elements the same way.  
The serializer itself carries no schema knowledge. All tag/type/attach mappings, and now all value-serialization logic, come from the injected `XmlModelRegistry`.

- `XmlModelSerializer::serialize()` and `writeAttributes()` now take a `const XmlModelRegistry&`, threaded through both overloads (plain and namespaced) and through `serializeChildren()`.
    
- `writeAttributes()` calls `registry.serializeType(propertyMetaTypeName, value, ok)`, looking up a `TypeSerializer` function keyed by the property's meta-type name (via `QMetaType::name()`).
    
- `XmlModelRegistry`'s old separate enum/generic converters are unified into a single `TypeSerializer` (`QVariant -> QString`) concept, with a new default constructor registering baseline serializers (bool, QString, int) and `buildTracklabelRegistry()` layering schema-specific ones on top (also fixes `ControlTypeList` round-tripping and adds one for `StringList`).
    
- The exporter now registers the XML namespace once on the document root instead of redeclaring it on every element.
    

Model changes (default values from tracklabel.xsd): most attribute models (`ExtendedTrackLabelModel`, `TrackLabelConfigModel`, `ContextMenuItemModel`, `FieldAppearance`, `FieldLayout`, `FieldText`) now define named `Default*` constants and skip adding a key-value pair to `xmlAttributeMap()` when the current value still matches the default.

Also: `FontSizeDelta` is now a real enum (was a validated `int`), with string conversion helpers and a `Q_INVOKABLE` for exposing valid values to QML; `TrackLabelModel` gained an `ensureTrailingEmptyRow()` helper that both fixes and simplifies the previous repeated trailing-row insertion logic.
