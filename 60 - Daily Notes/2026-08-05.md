### Removing empty tracklabel lines

I want you to implament something in this direction. This approach will relieve the stress of The dataController to handle removing FieldList instances when extendedTracklabel[rowIdx] is empty/nonExistant and currentTrackLabel[rowIdx] is also emptyExistant. This would rather happend between instance of TrackLabelModel derived Qobjects.

Solution 1: Use a Static Event Bus (Recommended)

This approach completely eliminates the need for instances to know about each other. They connect to a shared, static backbone interface.

Step A: Define the Static Hub

cpp

```
// TrackLabelEventBus.h
#pragma once
#include <QObject>

class TrackLabelEventBus : public QObject {
    Q_OBJECT
signals:
    // Global broadcasting channel
    void globalRowCountChanged(QObject* sourceInstance, int newCount);

public:
    static TrackLabelEventBus& instance() {
        static TrackLabelEventBus bus;
        return bus;
    }
private:
    TrackLabelEventBus() = default;
};
```

Use code with caution.

Step B: Connect in the Base Class Constructor

Because all 5 of your objects derive from `TrackLabelModel`, you can write the connection logic **once** inside the base class constructor. Every instance will automatically register themselves to listen and talk to the bus.

cpp

```cpp
// TrackLabelModel.cpp (Base Class)
#include "TrackLabelEventBus.h"

TrackLabelModel::TrackLabelModel(QObject* parent) : QObject(parent) {
    // 1. Listen to the global bus
    connect(&TrackLabelEventBus::instance(), &TrackLabelEventBus::globalRowCountChanged,
            this, &TrackLabelModel::handleSiblingRowCountChanged);
}

// Every instance implements this to catch sibling updates
void TrackLabelModel::handleSiblingRowCountChanged(QObject* sourceInstance, int newCount) {
    if (sourceInstance == this) {
        return; // Ignore our own broadcast!
    }
    
    qDebug() << this << "received notification: Sibling" << sourceInstance << "changed count to" << newCount;
    // Your logic to react to the other models goes here
}
```

Use code with caution.

Step C: Broadcast the Change from the Child Class

Inside your `FieldListModel` (or whichever derived model tracks the actual data mutations):

cpp

```cpp
// FieldListModel.cpp
FieldListModel::FieldListModel(QObject* parent, QVector<FieldInterface*> fields)
    : TrackLabelModel(parent), m_fields(fields) 
{
    // When our rows change, blast it to the global bus
    connect(this, &QAbstractListModel::rowsInserted, this, [this]() {
        emit TrackLabelEventBus::instance().globalRowCountChanged(this, this->rowCount());
    });
    
    connect(this, &QAbstractListModel::rowsRemoved, this, [this]() {
        emit TrackLabelEventBus::instance().globalRowCountChanged(this, this->rowCount());
    });
}
```
